EdenWarden Documentation

Getting Started

EdenWarden is a security tool that helps you manage USB devices, clipboard history, and system activity logs.

Features

  • USB Protection: Control which USB devices can access your system
  • Clipboard Manager: Track and manage your clipboard history
  • Activity Logs: Monitor system events and activities
  • Reports: Generate detailed reports of system activity

Troubleshooting

USB device not working: Check if the device is in your whitelist in the USB Manager.

Clipboard not saving: Ensure clipboard history is enabled in settings.

High memory usage: Reduce log retention period in settings.
